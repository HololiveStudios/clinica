# Clínica SaaS - Sistema de Gestão Médica e Prontuário

## 1. Objetivo e Finalidade
Software completo para consultórios e clínicas médicas com agendamento de consultas, cadastro de pacientes e prontuário eletrônico.

## 2. Tecnologias Utilizadas
- React, TypeScript, Vite, Node.js/Express (Backend), Axios, React Hook Form, Tailwind CSS

## 3. Arquitetura e Estrutura de Diretórios
Arquitetura cliente-servidor completa com API REST em Node.js (`server/` ou scripts de inicialização) e frontend em React.

## 4. Principais Arquivos e Responsabilidades
- `server/` ou `index.js`: Rotas da API médica.
- `src/`: Telas de recepção, agenda e ficha do paciente.

## 5. Funcionalidades Identificadas
- Agenda médica com visão diária e semanal
- Prontuário eletrônico do paciente com histórico de atendimentos
- Cadastro de profissionais de saúde e especialidades

## 6. Como Compilar ou Executar
```bash
npm install
npm run dev
```

## 7. Estado Atual do Projeto
**Completo**

## 8. Pendências e Limitações Identificadas
Módulo de prescrição digital com assinatura em certificado ICP-Brasil.
